About this test

This page exists to verify a full workflow: writing HTML/CSS locally, downloading image assets, pushing everything to a GitHub repository, and hosting the result on a static host (GitHub Pages). No backend, no build step — just plain files served as-is.

What's in the pipeline

1. Local files

HTML, CSS, and downloaded image assets authored in a plain project folder.

2. GitHub repo

Everything committed and pushed to a public repository for version control.

3. Static hosting

GitHub Pages serves the repo directly — no server, no database.
